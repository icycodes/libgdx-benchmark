# libGDX Headless Authoritative Match-Replay Server ## Background libGDX ships a `gdx-backend-headless` backend whose intended use case is running an authoritative game server (or CI-runnable replay/simulation) that shares its `core` simulation module with a graphical client. The headless backend supplies a real `HeadlessApplication` that drives the `ApplicationListener` lifecycle on a dedicated thread, plus mock implementations of `Graphics`, `Audio`, and `Input` so the rest of libGDX (`Gdx.files`, math, JSON, `Array`, etc.) still works. The world width and height, the initial player positions, and the per-tick commands are all driven by the input match log (see format below). The simulation logic (movement, clamping, command application) **must** live in the `core` module so it could be reused by a graphical client. 4. **Headless launcher in `server`**: * Construct a `HeadlessApplication` whose `ApplicationListener` (e.g. an `ApplicationAdapter` subclass) drives the simulation. * Configure `HeadlessApplicationConfiguration.updatesPerSecond` so the loop ticks quickly (any value `>= 60` is acceptable). * Implement a custom `MockInput` subclass (from `com.badlogic.gdx.backends.headless.mock.input.MockInput`) that exposes the per-tick command set to the simulation, and replace `Gdx.input` with this subclass after the `HeadlessApplication` has been constructed. * Call `Gdx.app.exit()` once every tick in the log has been applied, then wait for the headless main-loop thread to finish before writing the transcript. 5. **Match log format** (UTF-8 plain text, LF line endings, parsed top-to-bottom): * Lines starting with `#` and blank lines are ignored. * Exactly one `WORLD <W> <H>` directive, where `W` and `H` are positive integers in `[1, 64]`. * One or more `START <player_id> <x> <y>` directives, with `player_id` in `[1, 4]`, declaring each player's initial cell (coordinates inside the world). * Zero or more `<tick> <player_id> <COMMAND>` lines where `tick` is a non-negative integer and `COMMAND` is one of: `MOVE_UP`, `MOVE_DOWN`, `MOVE_LEFT`, `MOVE_RIGHT`, `NOOP`. * The total tick count of the simulation equals `max(tick) + 1` across all command lines, or `0` if no command lines are present. 6. **Coordinate semantics**: * Origin `(0, 0)` is the bottom-left cell. `MOVE_RIGHT` increases `x`, `MOVE_LEFT` decreases `x`, `MOVE_UP` increases `y`, `MOVE_DOWN` decreases `y`. `NOOP` leaves the position unchanged. * Positions are clamped to `[0, W-1] x [0, H-1]`; an out-of-bounds move leaves the player in place. * At each tick `t`, commands for that tick are applied in ascending `player_id` order. A player without a command at tick `t` does not move that tick. 7. **Transcript output**: When invoked with two positional arguments `<input_log_path>` and `<output_transcript_path>`, the server must write a UTF-8 JSON file to `<output_transcript_path>` with the following exact shape (no extra fields): ```json { "world": { "width": <int>, "height": <int> }, "players": [ { "id": <int>, "startX": <int>, "startY": <int>, "finalX": <int>, "finalY": <int> } ], "totalTicks": <int>, "commandsApplied": <int>, "stateHash": "<sha256-hex>" } ``` Rules for the transcript fields: * `players` is sorted by `id` ascending and includes every player declared by a `START` directive. * `commandsApplied` counts every command line in the log (including `NOOP`), but excludes commands referencing players that were never declared with `START` (such commands must be ignored, not counted). * `totalTicks` is the value defined in requirement 5. * `stateHash` is the lowercase hexadecimal SHA-256 of the UTF-8 bytes of the canonical state string: `W=<width>;H=<height>;P=<id1>:<x1>,<y1>|<id2>:<x2>,<y2>|...|<idN>:<xN>,<yN>` where players are listed in ascending id order using their final positions. Decimal integers without padding (e.g. `W=8;H=8;P=1:3,1|2:6,7`). ## Implementation Hints * Read the `HeadlessApplication.java` source: the main loop calls `listener.create()` once and then `listener.render()` on every tick (after draining `postRunnable` queues via `executeRunnables()`).
