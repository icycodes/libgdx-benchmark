## Key Implementation Details

- **`Main.java`**: Validates exactly 3 args, creates `HeadlessApplicationConfiguration(upsPerSecond=60)`, boots `HeadlessApplication`, finds the `"HeadlessApplication"` thread by name and joins it to wait for completion.
- **`SplineSampler.java`**: In `create()`, loads the spline JSON via `JsonReader`, parses control points into `CatmullRomSpline<Vector2>`, reads t values from the input file (skipping blank lines), and opens the CSV output with a header. Each `render()` call consumes one t value, samples `valueAt()` and `derivativeAt()`, writes a row with `Locale.ROOT` formatting, then calls `Gdx.app.exit()` when done. Uses a `finished` guard to prevent double-logging on the final render tick.
- **`run.sh`**: Runs `./gradlew build -q` then `./gradlew run -q --args="..."` with the three positional arguments.
- **No `Gdx.gl*` calls** — only `Gdx.app.log/error` and `Gdx.app.exit()` are used.
- **Output format**: UTF-8 CSV, header `tick,t,x,y,speed`, all floats formatted with `%.6f` via `Locale.ROOT`, trailing newline after last row.
