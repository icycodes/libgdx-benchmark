# Animation Keyframe Sampler (libGDX Headless Backend) ## Background libGDX ships a generic `com.badlogic.gdx.graphics.g2d.Animation<T>` class used to drive frame-by-frame animation playback in games. The class is purely time-based logic (no OpenGL state), so it can be exercised entirely under the `gdx-backend-headless` runtime for deterministic offline simulations, CI checks, or replay tooling. The order of the resulting output lines must match the order of `sample` directives in the file. - Output file format (UTF-8 text).
