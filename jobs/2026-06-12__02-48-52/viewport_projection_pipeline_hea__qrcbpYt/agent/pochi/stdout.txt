The headless backend ships with `MockGraphics`, so no real OpenGL context exists, but the math behind `Camera`/`Viewport`/`Vector3` is plain Java and runs perfectly under `HeadlessApplication`. Your job is to build a deterministic CLI tool — `viewport-projector` — that boots libGDX's headless backend, replays a scripted sequence of window resize events and world points read from a JSON scenario file, and writes the resulting screen-space coordinates (and an unproject round-trip check) to an output log file.
