## Key Implementation Details

- **Launcher.java**: Accepts `<config_path> <output_path>` CLI args, creates `HeadlessApplicationConfiguration` with `updatesPerSecond = 0` (run as fast as possible), and boots `AnimationListener` via `HeadlessApplication`.

- **AnimationListener.java**: In `create()`:
  1. Reads the config file via `Gdx.files.absolute()`
  2. Parses directives: `frameDuration`, `playMode`, `keyFrames`, `sample` (handles `#` comments and blank lines)
  3. Constructs `Animation<Integer>` with the keyframes and play mode
  4. For each sample, calls `animation.getKeyFrame(stateTime)` (no-arg overload, respects play mode) and `animation.isAnimationFinished(stateTime)`
  5. Writes output lines as `<rawTime> <keyFrameValue> <finished>` via `Gdx.files.absolute().writeString()`
  6. Calls `Gdx.app.exit()` to terminate cleanly

- **LOOP**: Wraps around via modulo
- **REVERSED**: Plays backwards, clamps to first frame
- **LOOP_REVERSED**: Plays backwards with wrapping
- **LOOP_PINGPONG**: Bounces back and forth
